# Feed Mixer – test build

Test version of the Feed Mixer app for trying out on a phone or tablet. This is not the final version.

**Open the app:** https://joedejong.github.io/feed-mixer-test/

- Open the link in Chrome (Android) or Safari (iPhone). You can use "Add to Home screen" to open it like an app.
- On first launch it asks you to set up a manager with a 4–6 digit PIN. Add more users under **Users**.
- The scale starts in **Simulator** mode: start a load and tap **Simulate a bucket** to fake loader buckets.
- Everything you enter stays on your own device. Nothing is shared with other testers.
